# FSF Formal Definition (Version 1.0)

## 1. Purpose

The Feature Stability Framework (FSF) is a signal stratification framework designed to classify candidate biological signals according to their reproducible behavior under repeated dataset perturbation.

FSF evaluates signal behavior rather than statistical significance.

FSF is intended as a downstream characterization layer that operates on candidate feature sets generated by external analytical methods.

---

## 2. Inputs

FSF requires:

* Expression matrix
* Candidate feature list
* Sample metadata
* Perturbation scheme

Candidate features may originate from:

* DESeq2
* limma
* edgeR
* Boruta
* MDFS
* LASSO
* Other external methods

---

## 3. Perturbation Definition

A perturbation is a controlled modification of sample composition while preserving the biological condition being studied.

Examples include:

* Bootstrap resampling
* Random sample removal
* Leave-one-sample-out
* Leave-one-subgroup-out
* Leave-one-timepoint-out

Artificial noise injection is not part of the core framework.

---

## 4. Signal State Assignment

For each feature i and perturbation p, an effect estimate is calculated:

E(i,p)

The effect estimate must be derived using the same analytical procedure across all perturbations.

The default implementation may use log fold change (logFC), although alternative effect estimates may be used provided they remain consistent throughout the analysis.

Signal states are assigned as:

UP:
E(i,p) > +τ

DOWN:
E(i,p) < -τ

CONST:
−τ ≤ E(i,p) ≤ +τ

Default threshold:

τ = 0.5

The threshold remains user-configurable.

---

## 5. State Probabilities

For N perturbations:

Pup(i) = Number of UP assignments / N

Pdown(i) = Number of DOWN assignments / N

Pconst(i) = Number of CONST assignments / N

Constraint:

Pup(i) + Pdown(i) + Pconst(i) = 1

---

## 6. Signal Stratification Index (SSI)

For each feature:

SSI(i) = max(Pup(i), Pdown(i), Pconst(i))

SSI measures assignment confidence.

Interpretation:

SSI = 1.0
Perfectly stable assignment

SSI ≥ 0.9
Highly stable assignment

SSI ≥ 0.8
Stable assignment

SSI between 0.5 and 0.8
Intermediate assignment certainty

SSI < 0.5
Strong assignment uncertainty

SSI is not an instability score.

---

## 7. Classification Rule

Define:

Tstable = 0.80

Stable Up:

Pup ≥ Tstable

Stable Down:

Pdown ≥ Tstable

Stable Constant:

Pconst ≥ Tstable

Unstable:

All remaining features

---

## 8. Signal Classes

FSF Version 1.0 contains four classes:

* Stable Up
* Stable Down
* Stable Constant
* Unstable

No additional classes are defined in Version 1.0.

---

## 9. Biological Interpretation

Stable Up:
Consistently activated signals.

Stable Down:
Consistently suppressed signals.

Stable Constant:
Constitutive signals.

Unstable:
Signals exhibiting inconsistent behavior across perturbations.

---

## 10. Framework Outputs

For every feature, FSF returns:

* Pup
* Pdown
* Pconst
* SSI
* Assigned class

These outputs constitute the core FSF signal stratification profile.

---

## 11. Scope

FSF is designed to characterize signal behavior under heterogeneity and perturbation.

FSF does not replace:

* Differential expression analysis
* Feature selection
* Machine learning classification
* Statistical hypothesis testing

FSF functions as a signal stratification framework only.
